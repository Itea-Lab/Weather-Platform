# CloudFront Distribution Setup

## Overview

This document describes the CloudFront CDN setup for distributing processed weather datasets. The CloudFront distribution provides global access to CSV files generated by the Glue ETL pipeline.

This implementation uses **CDK Custom Constructs** integrated with CDK-based S3 storage to eliminate circular dependencies and provide better control over policies.

## Prerequisites

- CDK Storage bucket deployed (not Amplify storage)
- S3 bucket containing processed datasets
- IAM permissions for CloudFront service
- Origin Access Control (OAC) configuration

## CDK Implementation

The CloudFront distribution is implemented as a CDK custom construct that integrates directly with the CDK storage bucket:

```typescript
export function createCustomCloudFront(backend: any, weatherBucket: Bucket) {
  // Create Origin Access Control
  const originAccessControl = new OriginAccessControl(backend.stack, "OAC", {
    description: "OAC for Weather Dataset Bucket",
    originAccessControlOriginType: OriginAccessControlOriginType.S3,
    signing: Signing.SIGV4_ALWAYS,
  });

  // CloudFront distribution with direct bucket reference
  const distribution = new Distribution(
    backend.stack,
    "WeatherDatasetDistribution",
    {
      defaultBehavior: {
        origin: new S3Origin(weatherBucket, {
          originAccessControl: originAccessControl,
        }),
        allowedMethods: AllowedMethods.ALLOW_GET_HEAD,
        viewerProtocolPolicy: ViewerProtocolPolicy.REDIRECT_TO_HTTPS,
        cachePolicy: CachePolicy.CACHING_OPTIMIZED,
      },
    }
  );

  // Direct bucket policy integration - no circular dependencies
  weatherBucket.addToResourcePolicy(
    new PolicyStatement({
      sid: "AllowCloudFrontAccess",
      effect: Effect.ALLOW,
      principals: [new ServicePrincipal("cloudfront.amazonaws.com")],
      actions: ["s3:GetObject"],
      resources: [weatherBucket.arnForObjects("*")],
      conditions: {
        StringEquals: {
          "AWS:SourceArn": `arn:aws:cloudfront::${backend.stack.account}:distribution/${distribution.distributionId}`,
        },
      },
    })
  );

  return distribution;
}
```

### Key CDK Benefits

- **No Circular Dependencies**: Direct bucket policy management instead of separate policies
- **Clean Resource References**: Uses CDK bucket object directly
- **Automatic OAC Setup**: Origin Access Control configured automatically
- **Integrated Permissions**: Bucket policies managed within the same construct

## Configuration

### Distribution Settings

- **Price Class**: PriceClass_200 (US, Canada, Europe, Asia, Middle East, Africa)
- **HTTP Version**: HTTP/2 and HTTP/3 support
- **Viewer Protocol**: HTTPS only
- **Compression**: Enabled (Gzip and Brotli)

### Origin Configuration

- **Origin Type**: S3 bucket (CDK-created)
- **Origin ID**: weather-dataset-s3-origin
- **Domain Name**: CDK storage bucket domain name
- **Origin Access Control**: Automated OAC for secure access
- **Integration**: Direct bucket reference without policy conflicts

### Cache Behavior

- **Allowed Methods**: GET, HEAD, OPTIONS
- **Cached Methods**: GET, HEAD, OPTIONS
- **Default TTL**: 1 day (86400 seconds)
- **Maximum TTL**: 30 days (2592000 seconds)
- **Minimum TTL**: 1 hour (3600 seconds)

### Security Headers

Whitelisted headers for CORS support:

- Access-Control-Request-Headers
- Access-Control-Request-Method
- Origin

## Deployment

### CDK Resource Creation

The CloudFront distribution is created using AWS CDK in the Amplify backend:

```typescript
// Create Origin Access Control
const originAccessControl = new cloudfront.CfnOriginAccessControl(
  this,
  "OriginAccessControl",
  {
    originAccessControlConfig: {
      name: `${id}-weather-dataset-oac`,
      originAccessControlOriginType: "s3",
      signingBehavior: "always",
      signingProtocol: "sigv4",
    },
  }
);

// Create CloudFront Distribution
const distribution = new cloudfront.CfnDistribution(
  this,
  "WeatherDatasetCDNDistribution",
  {
    distributionConfig: {
      enabled: true,
      origins: [
        {
          id: "weather-dataset-s3-origin",
          domainName: props.storageBucketDomainName,
          originAccessControlId: originAccessControl.ref,
        },
      ],
      defaultCacheBehavior: {
        targetOriginId: "weather-dataset-s3-origin",
        viewerProtocolPolicy: "https-only",
        cachePolicyId: cachePolicy.ref,
      },
    },
  }
);
````

### Integration with Amplify Backend

The CloudFront resource is integrated in `amplify/backend.ts` with CDK storage:

```typescript
// Create CDK storage bucket first
const weatherBucket = createWeatherDatasetStorage(backend);

// Create CloudFront CDN with direct bucket reference
const cloudFrontDistribution = createCustomCloudFront(backend, weatherBucket);

// Export outputs for frontend use
backend.addOutput({
  custom: {
    weatherCdnDomainName: cloudFrontDistribution.domainName,
    weatherCdnDistributionId: cloudFrontDistribution.distributionId,
    weatherDatasetBucket: {
      bucketName: weatherBucket.bucketName,
      bucketDomainName: weatherBucket.bucketDomainName,
    },
  },
});
```

## Security Considerations

### Origin Access Control

- Prevents direct S3 access
- Uses SigV4 signing for secure requests
- Restricts access to specific distribution

### HTTPS Enforcement

- All requests must use HTTPS
- Default CloudFront certificate provided
- Modern TLS protocols supported

### Bucket Policy Security

- Denies external access except through CloudFront
- Allows account principals for management access
- Restricts access to specific S3 prefixes

## Troubleshooting

### Common Issues

1. **403 Forbidden Errors**

   - Verify Origin Access Control configuration
   - Check S3 bucket policy permissions
   - Ensure distribution status is deployed

2. **Cache Issues**

   - Use CloudFront invalidation for immediate updates
   - Check TTL settings and cache headers
   - Verify cache key configuration

3. **CORS Errors**
   - Confirm headers whitelist includes CORS headers
   - Check origin response headers
   - Verify cache policy configuration

### Debugging Steps

1. Test direct S3 access (should be denied)
2. Verify CloudFront can access origin
3. Check distribution deployment status
4. Review CloudWatch metrics and logs
5. Test with different query parameters
